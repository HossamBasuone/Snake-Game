# 🐍 Snake Game

A classic Snake game built using **HTML, CSS, and Vanilla JavaScript**. Control the snake, eat apples, increase your score, and challenge yourself with different difficulty levels and game modes.

## 🎮 Features

- **Three Difficulty Levels:** Choose between Easy, Normal, and Hard.
- **Two Game Modes:**
  - Walls: Hitting the board boundaries ends the game.
  - Endless: Move through one edge and appear on the opposite side.
- **Dynamic Speed:** The snake gets faster as you eat more apples.
- **Score System:** Track your current score and best score.
- **Saved Progress:** Best scores are stored locally for each difficulty and game mode.
- **Multiple Controls:** Play using keyboard, touch gestures, or on-screen buttons.
- **Pause & Restart:** Pause, resume, or restart the game whenever you want.
- **Theme Support:** Automatically adapts to your system's light or dark theme.
- **Responsive Design:** Play on desktop and mobile devices.

## 🕹️ Controls

| Action | Control |
|---|---|
| Move Up | ↑ or W |
| Move Down | ↓ or S |
| Move Left | ← or A |
| Move Right | → or D |
| Pause / Resume | Space |
| Start Game | Enter |
| Mobile Controls | Swipe or use on-screen buttons |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- HTML Canvas API
- Local Storage API
